This is a bonus project developed during the **Fundamentals** module of the **Trybe Web Development** course. The main goal was to practice and apply concepts of **JavaScript**, **CSS**, and **HTML** in a simple task organizer. The project involved working with the files `script.js`, `index.html`, and `style.css`.

## Features
The application allows you to:

- Add tasks to the list.
- Mark a task as completed with a **double click**.
- Remove completed tasks.
- Clear all tasks from the list.

## Skills Developed

During the development of this project, the following skills were improved:

1. Manipulation of elements in the **DOM**.
2. Use of **Web Storage** to store data in the browser.
3. Application of **programming logic** in a real-world context.
4. Use of **loop structures**.
5. Application of **conditional statements**.
6. Writing and using **functions** to modularize the code.
