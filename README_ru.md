Этот проект был разработан как дополнительное задание в модуле **Основы** курса **Веб-разработки в Trybe**. Основная цель проекта – практика и применение концепций **JavaScript**, **CSS** и **HTML** для создания простого органайзера задач. Проект включает работу с файлами `script.js`, `index.html` и `style.css`.

## Функционал
Приложение позволяет:

- Добавлять задачи в список.
- Отмечать задачу как выполненную с помощью **двойного клика**.
- Удалять выполненные задачи.
- Удалять все задачи из списка.

## Развитые навыки

Во время разработки этого проекта были улучшены следующие навыки:

1. Манипуляция элементами в **DOM**.
2. Использование **Web Storage** для хранения данных в браузере.
3. Применение **логики программирования** в реальном контексте.
4. Использование **циклов**.
5. Применение **условных операторов**.
6. Написание и использование **функций** для модульного кода.

1. Клонируйте этот репозиторий:  
   ```bash

   ```
2. Перейдите в каталог проекта:  
   ```bash
   cd project-todo-list
   ```
