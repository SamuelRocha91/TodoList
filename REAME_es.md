Este es un proyecto extra desarrollado durante el módulo de **Fundamentos** del curso de **Desarrollo Web de Trybe**. El objetivo principal fue practicar y aplicar conceptos de **JavaScript**, **CSS** y **HTML** en un organizador de tareas simple. El proyecto involucró la manipulación de los archivos `script.js`, `index.html` y `style.css`.

## Funcionalidades
La aplicación permite:

- Agregar tareas a la lista.
- Marcar una tarea como completada con un **doble clic**.
- Eliminar tareas completadas.
- Borrar todas las tareas de la lista.

## Competencias Desarrolladas

Durante el desarrollo de este proyecto, se mejoraron las siguientes competencias:

1. Manipulación de elementos en el **DOM**.
2. Uso de **Web Storage** para almacenar datos en el navegador.
3. Aplicación de **lógica de programación** en un contexto real.
4. Uso de **estructuras de repetición**.
5. Aplicación de **condicionales**.
6. Escritura y uso de **funciones** para modularizar el código.
