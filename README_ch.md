这是在**Trybe Web开发课程**的**基础模块**中开发的额外项目。项目的主要目标是实践和应用**JavaScript**、**CSS**和**HTML**的概念，创建一个简单的任务管理器。项目涉及到对 `script.js`、`index.html` 和 `style.css` 文件的操作。

## 功能
该应用程序允许：

- 向列表中添加任务。
- 通过**双击**标记任务为已完成。
- 删除已完成的任务。
- 清空所有任务。

## 开发中掌握的技能

在开发这个项目的过程中，我提升了以下技能：

1. **DOM** 元素的操作。
2. 使用 **Web Storage** 存储浏览器中的数据。
3. 将**编程逻辑**应用于实际情境中。
4. 使用**循环结构**。
5. 应用**条件语句**。
6. 编写并使用**函数**来模块化代码。

## 如何运行

1. 克隆此存储库：  
   ```bash
   git clone https://github.com/你的用户名/project-todo-list.git
   ```
2. 进入项目目录：  
   ```bash
   cd project-todo-list
   ```
3. 在浏览器中打开 `index.html` 文件。
